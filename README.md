# Meridian

Real-time cash visibility for finance teams. A concept landing page design.

**Live Demo**: [https://meridian-landing-psi.vercel.app](https://meridian-landing-psi.vercel.app)

## Tech Stack

Built with vanilla web technologies (no JS frameworks):

- **HTML5** for semantic structure
- **CSS3** with custom properties (Vanilla CSS)
- **GSAP** (GreenSock Animation Platform) for high-performance scroll and micro-animations
